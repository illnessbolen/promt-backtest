# Этап 1: выгрузка истории (@bosona)

Дата: 2026-09-29. БД: `data/bosona.db` (SQLite, ~1.1 ГБ, в git не входит). Команды — в `README.md`.

## Что сделано

Пакет `src/bosona`:

| Модуль | Что делает |
|---|---|
| `http.py` | async-клиент на httpx: лимит запросов по хостам, ретраи с экспоненциальной паузой, учитывает `Retry-After` |
| `db.py` | схема SQLite, `INSERT OR IGNORE` / upsert, `sync_state` |
| `parse.py` | чистые функции: нормализация строк Data API v2, ключи дедупликации, разбор slug, режим резолва, разбор рынков Gamma, формула комиссии |
| `sync_history.py` | `/v2/activity` (все строки кошелька) + `/v2/trades?taker_only=true` (роль); окна по 7 дней обходятся параллельно |
| `sync_markets.py` | Gamma `/markets?condition_ids=…&closed=true` с вложенным event: метаданные, итог, strike/final |
| `verify.py` | сверка с `/v2/user-volume` по дням, `/v2/user-stats`, `/v2/user-pnl` |
| `cli.py` | `init-db`, `sync [--full]`, `sync-history`, `sync-markets`, `verify`, `stats` |

Тесты: 30 штук (`tests/test_parse.py`, `tests/test_dedup.py`), на реальных ответах API из `docs/samples/stage0/`. Проверяют:

- разбор slug, режимов резолва и рынков;
- ключи дедупликации: одинаковые fills в одной tx, повторная вставка, перекрытие окон, «долечивание» частично проиндексированной tx;
- роль и комиссию.

## Сомнения и ограничения

- `fee_usdc` считается по формуле на средней цене fill'а. Для taker-ордеров, прошедших несколько уровней, возможны расхождения в 5-м знаке.
  Точные комиссии есть on-chain (`OrderFilled.fee`); колонки для такого обогащения в схеме есть.
- Strike (`priceToBeat`) есть у 95.0% закрытых рынков эпохи спота Chainlink (38 445 из 40 489). В TWAP-эпохе покрытие 99.9–100%.
  Пропуски на этапе 2 восполняем по цепочке соседних окон. Их нужно догружать по slug, потому что он торговал не каждое окно.
- Один рынок завис открытым с 2026-08-05 (`btc-updown-5m-1785941700`), итог по нему неизвестен.
- Публичный RPC (`publicnode`) не находит транзакции по хешу старше ~40 дней. `eth_getLogs` по старым блокам работает.
  Calldata ордеров доступна только для свежих tx.
- Data API v1 выключается 2026-10-24. Код использует только v2.
